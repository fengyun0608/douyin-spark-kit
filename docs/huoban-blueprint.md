## 二、与星语的关系

**硬约束：星语不动。**

```
星语（Xingyu）
  /api/douyin/*      ← 一行不改，继续服务星语 App

伙伴（SparkPal）
  /api/spark/*       ← 新命名空间，独立表、独立配额、独立订阅
```

共享的只有：
```
· 开源仓库里的协议实现（二维码登录、私信发送）
· 同一台服务器的运行时（PM2 进程隔离）
· 同一个 nginx（按路径分流）
```

数据库表前缀区分：`Huo*` vs 现有的 `Douyin*`，互不干扰。

## 三、登录后流程（产品核心）

### 3.1 首次进入四步，每步只做一件事

```
① 手机号登录
     一句话价值 + 「已有 12,847 人的火花被保住」

② 绑定抖音
     点「绑定」→ 服务端出二维码（排队显示第 N 位）
     → 扫完拉起抖音 App 确认 → 自动回填头像昵称

③ 拉好友（带进度条）
     「正在读取你的 674 位好友…」
     完成后直接给出按火花天数排序的列表

④ 一键开始
     火花最长的前 10 位默认已勾选
     用户只需点「就这样，开始守护」
```

**关键设计**：第 ④ 步不给空列表。用户第一次进来就已经「配置好了」，只需要确认。

## 四、商业化：按绑定账号

### 4.1 套餐

| | 免费 | 专业 ¥12/月 · ¥98/年 | 团队 ¥299/月 |
|---|---|---|---|
| 抖音账号 | 1 | 3 | 20 |
| 好友上限 | 10 | 全部 | 全部 |
| 每日发送 | 5（软上限） | 50 | 500 |
| 随机偏移 | ❌ | ✅ | ✅ |
| 预览发送 | 每天 1 次 | 无限 | 无限 |
| 发送报告 | 7 天 | 90 天 | 永久 |
| 火花到期提醒 | ❌ | ✅ | ✅ |
| 设备数 | 1 | 3 | 不限 |

### 4.2 为什么按账号不按发送量

```
发送成本 ≈ 0（纯 HTTP，1000 账号 × 20 条/天 服务器毫无压力）
扫码成本 高（Chromium 300-400MB × 20 秒，必须排队）

按发送量收费 → 用户觉得被卡，且没有成本依据
按账号收费   → 用户理解成「我几个号」，自然，且对应真实资源占用
```

发送量只做**软上限**（防滥用 / 防批量骚扰）。

### 4.3 试用与转化

```
注册送 7 天专业版全功能
到期前 2 天推送：「你的 131 天火花靠它保住了」
               + 过去 7 天发送记录截图
首月 6 元（半价），降低第一次决策成本
```

### 4.4 支付

```
Android   微信 / 支付宝（自有码支付）
iOS       先不做（IAP 抽 30% + 审核风险）
```

## 五、开源策略（open-core）

### 5.1 三个仓库全 MIT

```
douyin-spark-kit    协议实现 + 逆向文档（已有）
sparkpal-app          Flutter 客户端
sparkpal-server       Go + Node 服务端 + docker-compose
```

### 5.2 收费的不是代码，是托管

```
免费   自己部署整套（docker-compose up），功能全开
       代价：自己买 4G+ 服务器、装 Chromium、跟抖音改版
云版   ¥12/月，我们托管，绑定账号额度
```

### 5.3 为什么这样更好

| | 闭源 | 开源 + 托管 |
|---|---|---|
| 传播 | 烧钱投放 | 技术社区自然扩散 |
| 信任 | 怕偷 cookie | 可审计 |
| 竞争 | 被抄袭 | 抄了也得自己运维 |
| 收费理由 | 「软件费」抗拒 | 「省你一台服务器 + 运维」接受 |

### 5.4 护城河

```
① 稳定性：能扛抖音改版（开源社区帮盯）
② 数据：火花历史、文案库、好友关系
③ 品牌：伙伴 = 续火花这件事
④ 迁移成本：绑了 3 个号 + 半年记录，不会走
```

### 5.5 风险：被 fork 自建

```
对策：
· 单用户自建要养 4G 内存 + 持续跟改版，普通人干不了
· 愿意折腾的人本来也不会付费
· 用 docker-compose 降低门槛反而扩大生态，转化的是「不想折腾的多数」
```

## 六、技术架构

```
┌────────────────────────────────┐
│ 伙伴 App  Flutter（Android）    │
└──────────────┬─────────────────┘
               │ /api/spark/*
┌──────────────▼─────────────────┐
│ Go 服务  spark-api              │
│ 认证 / 好友 / 任务 / 报告 / 订阅 │
├────────────────────────────────┤
│ Node 服务  spark-qr             │
│ Playwright 出二维码 + 排队      │
├────────────────────────────────┤
│ 调度器  按北京时间 60s tick      │
└──────────────┬─────────────────┘
               │
        MySQL  Huo* 表
```

**与星语同机部署，进程隔离**：
```
xingyu-server   Node  3100   星语业务
xingyu-go       Go    3101   星语 + 抖音模块
spark-api       Go    3200   伙伴 API
spark-qr        Node  3210   伙伴扫码
```

nginx 新增 `location /api/spark/` 分流到 3200。

## 八、安全要求

```
· cookie 必须 AES-256 加密入库，密钥走环境变量
· 任何接口不返回完整 cookie，只返回长度 / 是否有效
· 密码 bcrypt（cost 12），登录失败 5 次锁 15 分钟
· 注销 → 立刻物理删除 cookie 与好友数据
· 扫码会话与用户绑定，别人的 ticket 查不到
· 全站 HTTPS，证书自动续期
```

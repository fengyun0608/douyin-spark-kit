# 开源范围界定

## ✅ 开源（技术本身，无用户数据）

| 内容 | 价值 | 状态 |
|---|---|---|
| Playwright 二维码登录服务 | 抖音二维码怎么稳定拿到 | 已验证 |
| 二维码短链解码（`v.douyin.com`） | 网页二维码和拉起抖音的真实内容 | 已验证 |
| `snssdk1128://webview/?url=` 唤起方式 | 手机端"点一下自动拉起抖音" | 已验证 |
| `bd-ticket-guard-result: 1101` 的原因与解法 | 为什么纯 HTTP 拿不到关注列表 | 已验证 |
| IM 发送协议（protobuf 字段布局） | 不用浏览器直接发私信 | 已验证（7/7） |
| 每个会话独立 salt 的发现 | 跨会话发送 7100 的根因 | 已验证 |
| 错误码含义（7100 / 7905 / -14） | 少走弯路 | 已验证 |

## ❌ 不开源

| 内容 | 原因 |
|---|---|
| 星语 App 全部代码 | 商业产品（UI/主题/支付/账号/公告/热更新） |
| 服务器地址、域名、Token | 安全 |
| 任何 cookie、用户 ID、好友列表 | 隐私 |
| 品牌名、图标、文案 | 商标 |
| 定时调度 + 保活策略 | 商业逻辑 |

## ⚠️ 注意

- 仓库里所有示例使用占位符 `YOUR_COOKIE` / `YOUR_SEC_UID`
- 不提供任何抓取他人数据的工具，只处理**自己的账号**
- README 明确写：仅用于学习与自有账号自动化，遵守抖音用户协议
